## 渲染管线
1. 概念：渲染管线是unity将游戏场景中的模型、贴图、光照等数据转换为最终屏幕像素的完整过程，包含几何处理、光栅化、像素着色等关键阶段
    ```
    应用阶段：CPU（准备「画什么」）
        1. 脚本、动画改 Transform
        2. 剔除：视锥体外、被挡住的不画
        3. 排序、合批：能一起画的网格尽量合成一次提交
        4. 发出 Draw Call：一次「用这个 Shader、这批顶去画」

    集合阶段：总线
        顶数据、贴图、常量缓冲交到 GPU

    光栅化阶段：GPU（真的画）
        5. 顶点着色器：模型空间 → 裁剪空间（MVP）
        6. 光栅化：三角形变成像素
        7. 片元着色器：采样贴图、算光、出颜色
        8. 深度 / 模板 / 混合，写入 RenderTexture
        9. URP 后处理（Bloom、你做的 CRT）再画到屏幕
    ```
2. **Draw Call**：CPU 请 GPU 画一批。太多则 CPU 忙着发指令。
3. **SetPass**：换 Shader / 渲染状态，往往比多一次 Draw 更贵。合批是为了少切换。


### 渲染管线分类
1. 内置渲染管线(Build-in render pipeline)
- 特点：unity默认渲染管线，兼容全平台(包括低端设备)，但定制性差，仅支持基础渲染效果
- 适合2D游戏、快速原型开发或旧平台项目
2. 通用渲染管线(URP)
- 优势：
    - 跨平台优化(移动端/PC/VR)
    - 支持Shader Graph可视化编辑
    - 自启动GPU实例化与SRP Batcher
- 适用场景：中小型3D游戏或需要平衡画质与性能的项目
3. 高清渲染管线(HDRP)
- 核心能力：
    - 实时渲染、体积光照、PBR材质
    - 支持高端硬件(如DX12/vulkan)
- 使用场景：3A级游戏、建筑可视化等高清画质需求
4. 自定义渲染管线(SRP)
- 开发自由：通过C#脚本完全控制渲染流程，适合特殊风格(如卡通渲染)或专业领域(如仿真医学)

## SRP(unity Scriptable Render Pipeline)
1. 是unity引擎的一种高级渲染管线技术，允许开发者通过C#脚本完全自定义渲染流程，取代传统的固定功能渲染管线。
2. 特点：
- 灵活控制：SRP通过C#脚本控制渲染的每一步，包括剔除、光照计算、材质渲染、后处理等，开发者可以按需优化和实现特殊效果
- 模块化设计：基于RenderPipelineAsset(配置入口)和RenderPipeline(执行渲染逻辑)两个核心类，支持分层设计流程(如分Pass处理阴影、透明物体等)
- 性能优化：支持SRP Batch(减少CPU开销)、动态合批、GPU Instaning等优化技术、尤其适配多平台(移动端/PC/主机)

## 自定义SRP流程
### 一、管线结构基础
1. RenderPipelineAsset：创建管线资产的入口，继承自RenderPipelineAsset并且重写CreatePipeline()方法
2. RenderPipeline类：实现IRenderPipeline接口或继承RenderPipeline，核心逻辑在Render()方法中逐帧渲染

### 二、渲染控制流程
1. ScriptableRenderContext：unity提供的底层渲染上下文，通过Submit()提交指令(如绘制天空盒、集合体)
2. CommandBuffer：封装渲染命令(如清除目标、设置材质属性)需要配合ExecuteCommandBuffer()执行

### 三、Shader和材质兼容
1. Shader编写：需适配SRP的着色器标签(如LightMode = "ForwardBase")或者使用Unlit Shader作为起点
2. 材质兼容性：处理内置管线材质到SRP的迁移，或自定义ShaderGraph

### 四、性能优化
1. 剔除(Culling)：通过Camera.TryGetCullingParameters获取视锥剔除参数，减少不可见的物体渲染
2. 批次合并：利用SRP Bather优化相同材质的物体绘制

## 内置渲染管线迁移
### 一、准备工作
1. 项目备份：使用版本控制(Git/SVN)或者手动被封文件夹，避免不可逆的材质或者着色器损坏
2. 版本兼容性检查：URP/HDRP需要unity 2019.3或更高版本，建议使用unity 2021 LTS或者更高版本以获取稳定支持
3. 安装对应的package：通过Window > Package Manager安装Unity RP(URP)或High Definition RP(HDRP)

### 二、具体步骤
1. 创建URP配置资产
- 右键项目窗口：Create > Rendering > Unity Render Pipeline > Pipeline Asset生成URP主配置和渲染器资产
2. 切换默认渲染管线
- 打开Edit > Project Settings > Graphics，将Scriptable Render Pipeline Settings字段指向刚刚创建的URP资产
3. 材质转换和着色器转换
- 自动转换：使用Edit > Render Pipeline > Universal Render Pipeline > Upgrade Project Materials批量升级内置材质到URP兼容版本
- 手动修复：自定义着色器重写HLSL语言，替换CGPROGRAM为HLSLPROGRAM并且更新头文件(如UnityCG.cginc改为URP的Core.hlsl)
4. 光照和阴影调整
- URP的光照模型和内置管线不同，需要重新烘培光照贴图或调整光源参数(如光强和阴影分辨率)

## 摄像机
1. camera是unity用于渲染场景的组件
- Clear Flags：决定如何清除屏幕(Skybox/Solid Color/Depth Only/Don't Clear)
- Culling Mask：控制哪些图层(Layer)会被渲染
2. 如何实现分屏或多摄像机渲染
- 通过调整Viewport Rect属性来划分屏幕区域
```Csharp
    camera1.rect = new Rect(0, 0, 0.5f, 1); // left camera part
    camera1.rect = new Rect(0.5f, 0, 0.5f, 1); // right camera part
```
3. Camera的Clipping Planes(裁剪平面)
- Near：最近渲染距离，过小会导致近处物体裁剪(如UI消失)
- Far：最远渲染距离，过大会增加渲染负担
- 注意：地形渲染需要确保Far足够大，但要避免包含无关物体
4. 实现摄像机跟随角色平滑移动
```CSharp
void LateUpdate() {
    transform.position = Vector3.Lerp(transform.position, target.position + offset, 0.1f);
}
```
- 或者使用Cinemachine插件实现复杂的跟随逻辑(如轨迹、阻尼等)

## 面试题
### 1. 什么是渲染管线？ Unity中哪些主要类型？
- 渲染管线将3D场景数据转换成2D屏幕像素的流程，包括几何处理、光栅化、着色器等阶段
- 包含以下类型：内置管线、URP、HDRP、自定义SRP

### 2. 如何在SRP中实现后处理效果(如Bloom)
- 创建RenderFeature和RenderPass
- 使用CommandBuffer.Blit在临时RT间传递图像数据
- 编写Shader实现高斯模糊和亮度阈值过滤

### 3. URP中如何减少Overdraw
- 分层渲染：先渲染不透明物体(由近到远)再渲染透明物体(由远到近)
- Early-Z：通过深度Pass提前剔除不可见像素   

### 4. 光照和阴影优化的常见方式
- 阴影：使用级联(CSM)、降低阴影分辨率
- 光照：烘焙静态光照(lightMapping)、动态光源数量限制

### 5. 如何调试自定SRP的性能问题
1. 关键指标：Drawcall数量、RT切换次数、Shader复杂度
2. 工具：Frame Debugger\Profiler
