## 贪心的局部最优解
1. 写代码前先说明局部最优选择，并验证它是否能推出全局最优

### leetcode
1. leetcode 455. 分发饼干

```cpp
int findContentChildren(vector<int>& g, vector<int>& s) {
    sort(g.begin(), g.end());
    sort(s.begin(), s.end());
    int index = s.size() - 1;
    int res = 0;
    for (int i = g.size() - 1; i >= 0; --i) {
        if (index >= 0 && s[index] >= g[i]) {
            res++;
            index--;
        }    
    }
    return res;
}
```
